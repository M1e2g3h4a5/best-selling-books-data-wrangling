📊 Best Selling Books – End-to-End Data Analytics Project

📌 Project Overview
This project demonstrates a complete data analytics workflow from raw data to business insights using SQL and Power BI.

🔄 Project Workflow
- Data Cleaning & Preparation (SQL)
- Exploratory Data Analysis (EDA)
- Deep Dive Analysis
- Interactive Dashboard Development
- Data Storytelling & Statistical Validation

📊 Dataset Summary
- Total Books: 298
- Total Reviews: 29M+
- Average Rating: 4.67
- Average Price: $11.66

🔍 Key Insights
- Fiction & Action drives the highest reader engagement
- Ratings remain consistent across genres (~4.6+)
- Pricing has minimal impact on customer satisfaction
- Most books fall under the medium price category

📈 Tools Used
- MySQL
- Power BI
- GitHub

📂 Project Structure

Task 1 – Data Wrangling
- Data cleaning using SQL
- Handling missing values and formatting issues
- Creating analysis-ready dataset

Task 2 – Exploratory Data Analysis
- Identified trends in ratings, pricing, and genres
- Built initial Power BI dashboard

Task 3 – Deep Dive Analysis
- Genre performance analysis
- Price vs rating relationship
- Interactive dashboard with slicers
- Statistical validation of findings

Task 4 - Data Storytelling and Statistical Analysis
- Success in the book market comes from exceptional content in popular genres, not pricing strategies
